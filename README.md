# Guga LP - Landing Page

Uma landing page moderna e profissional desenvolvida com HTML, CSS e Bootstrap 5.

## 🚀 Características

- **Design Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Bootstrap 5**: Framework CSS moderno e robusto
- **UI/UX Moderno**: Interface limpa e intuitiva seguindo padrões de mercado
- **Performance**: Código otimizado e rápido
- **SEO Otimizado**: Meta tags e estrutura semântica
- **Acessibilidade**: Seguindo boas práticas de acessibilidade web

## 📋 Seções

1. **Hero**: Seção principal com call-to-action
2. **Recursos**: 6 recursos principais com ícones
3. **Sobre**: Informações sobre a empresa
4. **Depoimentos**: Avaliações de clientes
5. **CTA**: Chamada para ação
6. **Contato**: Formulário de contato
7. **Footer**: Rodapé com links e newsletter

## 🛠️ Tecnologias

- HTML5
- CSS3
- Bootstrap 5.3.2
- Bootstrap Icons
- JavaScript (ES6+)
- Google Fonts (Inter)

## 📱 Visualização

Para visualizar a landing page, basta abrir o arquivo `index.html` em seu navegador ou usar um servidor local:

```bash
# Usando Python
python3 -m http.server 8080

# Usando Node.js
npx http-server

# Usando PHP
php -S localhost:8080
```

Depois acesse: `http://localhost:8080`

## 📦 Estrutura de Arquivos

```
guga-lp/
├── index.html      # Página principal
```

## ✨ Funcionalidades JavaScript

- Navegação suave (smooth scroll)
- Menu responsivo
- Botão "voltar ao topo"
- Highlight automático de seção ativa
- Animações ao rolar a página
- Formulários interativos

## 🎨 Personalização

Para personalizar cores e estilos, edite as variáveis CSS no arquivo `styles.css`:

```css
:root {
    --primary-color: #0d6efd;
    --secondary-color: #6c757d;
    /* ... outras variáveis */
}
```
